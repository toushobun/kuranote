## 设计图中的约定

- 筛选或搜索时隐藏「常用商家」区块，只显示结果列表（设计图 2）。
- 快速路线中金额输入实时同步到对应明细；未填完金额时步骤「明细」不显示为已完成（设计图 0-B）。
- 点「记账」后的第一屏采用方案 b：直接进入商家选择（0-B 画面 ①），点「切换方式」弹出方式选择抽屉（设计图 1 画面 ①）。0-A 画面 ① 的方式选择页不再作为第一屏。
- 设计图 3 画面 ②、③ 的步骤进度条画错了（第 3 步的圆点写成了「4」且未显示为已完成）。正确表现：从确认页跳回某一步时，其余已完成的步骤都显示对勾，只高亮当前步骤，圆点数字与步骤名一一对应。
- 新流程的添加明细抽屉不显示「常用快捷」；明细为空时也使用同一张明细卡片，只显示「＋ 添加明细」一行；合计放在明细卡片最后一行（设计图 4）。
- 设计图 4 画面 ④ 的搜索框占位文字画成了「选择小分类」，正确为「搜索小分类」（沿用现有文案）。
- 设计图 6 画面 ② 的时间抽屉沿用现有日期时间选择器：「日期」「时刻」两行，同一时间只展开一项（图中为「日期」展开、「时刻」收起）；顶部为标题「时间」+ 关闭 ×，与备注抽屉一致。
- 时间抽屉的「时刻」与现有组件一样**保留秒**（选择和保存都到秒）；图中「12:30」未画出秒，以本条为准。确认页和交易列表等显示处只显示到分钟。
- 确认页备注为空时显示灰色占位「添加备注（可选）」，不显示「-」（设计图 6）。

## 设计图与最新规格的差异（实现时以本节和 Issue 正文为准）

以下规格在设计图定稿后才确定，旧图没有重画，实现时按这里的说明处理：

- **步骤是 4 步**：商家 · 账户 · 明细 · 确认。图中的 5 步进度条（含「备注时间」）作废；备注、时间在确认页点击对应行后弹出编辑框修改。
- **已选商家和收支账户合并为一张紧凑卡片**：从第 2 步开始显示在进度条下方，两行（商家一行、账户一行，各带「更换」），每行约 44px。图中商家、账户各占一张大卡片的样式作废。
- **明细全部填好金额后，底部按钮为「去确认」**，直接进入确认步骤。
- **付款分配在明细步骤内展开**，不单独设步骤。

## 修订（2026-10-29，设计图 7）

人工验收前的走查后，以下内容以设计图 7 为准，覆盖之前设计图中的对应部分：

- **去掉进度条下方的商家 / 账户摘要卡片**（包括紧凑卡片）。已完成的「商家」「账户」步骤在进度条步骤名下方第二行显示选中的值（单账户显示账户名，多账户显示「xx 等 N 个」），过长时省略。
- **确认页改为小票风格**（替代设计图 0-B、6 中的确认卡片）：锯齿上下边缘的纸片，内部只用虚线分隔，依次为抬头（商家头像、商家名、日期时间）→ 明细（品名与金额左右对齐，「＋ 添加明细」）→ 合计 → 支付（每个付款账户一行）→ 备注。不使用表格式的左标签列和每行右箭头。
- **编辑入口**：商家名、日期时间、每条明细、每个支付账户、备注的右侧各有一个浅色铅笔图标，所有铅笔对齐在小票最右侧同一条竖线上；头像旁和合计行不放铅笔。

## 修订（2026-10-29，设计图 8）

维护者验收后改为**两屏流程**，以下内容以设计图 8 为准，覆盖之前设计图（包括设计图 7）中的对应部分：

- **只有两屏**：选择商家 → 小票（确认页）→ 保存。去掉「账户」「明细」步骤，**去掉步骤进度条**和「下一步 / 去确认 / 完成，回到确认」按钮。设计图 0-A ~ 7 中的进度条、账户步骤、明细步骤、步骤内的付款分配均作废。
- **顶部**：选择商家页为左上角关闭 ×、标题「记一笔」、右侧「切换方式」；小票页为左上角返回 ←（回到选择商家，已填内容保留）、标题「从商家记账」、右上角关闭 ×。
- **账户在小票的「支付」区选择**：有历史时自动选推荐账户；没有历史（或建议获取失败 / 超时）时支付行显示「选择收支账户」并标红，选好之前「保存记账」禁用。点击后弹出账户选择抽屉（沿用原账户步骤的列表）。
- **明细在小票内编辑**：有自动明细时显示「已按你的习惯自动添加 N 条，填金额即可」；没有历史时显示「这家商家还没有记录」和「＋ 添加明细」。
- **小票细节（任务 10）**：明细行不显示「自动」标签，保留明细区上方的自动添加条数提示；明细行只显示带 emoji 的「大分类 · 小分类」名称，不再单独显示分类图标；合计行左侧「合计」与右侧「金额 + 支出 / 收入」两行整体垂直居中。
- **多账户付款分配在小票的「支付」区**：每个账户一行，最后一行显示对账（付款合计 = 明细合计）。
- **铅笔与删除**：
  - 抬头的商家名、日期时间：铅笔**紧跟在文字右侧**（按图 8，覆盖设计图 7「对齐在最右侧竖线」的规则）。
  - 明细行、支付行：每行右侧都有一个铅笔和一个删除 ×，明细与支付样式统一（图 8 中明细行缺 ×、PayPay 行缺 ×、现金行缺铅笔，以本条为准）。只剩一个付款账户时也显示 ×，删除后支付行回到「选择收支账户」。
- **金额可点击**：明细和支付行的金额都带「待输入」那种下划线，点击只打开金额键盘（图 8 画面 ④ 已填金额缺少下划线，以本条为准）。
- 图中与实现约定不一致、以实现为准的地方：
  - 合计字号以原明细卡片为准（橙色粗体，约 24px），图中偏大。
  - 明细使用分类名自带的 emoji，不另放图标（任务 10）；支付行使用账户类型图标（以后可能支持自定义账户图标）；图 8 画面 ④ 的插画图标和 PayPay 品牌 logo 不采用。
  - 提示条沿用现有样式，画面 ② 的橙色与画面 ③ 的红色不作区分。
  - 选中商家后的加载状态沿用现有实现，图中头像右上角的转圈不采用。
  - 单账户时支付金额等于明细合计，不可点击，以实现为准（上面「金额可点击」只适用于明细行和多账户的支付行）。
