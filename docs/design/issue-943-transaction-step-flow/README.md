## 设计图中的约定

- 筛选或搜索时隐藏「常用商家」区块，只显示结果列表（设计图 2）。
- 快速路线中金额输入实时同步到对应明细；未填完金额时步骤「明细」不显示为已完成（设计图 0-B）。
- 点「记账」后的第一屏采用方案 b：直接进入商家选择（0-B 画面 ①），点「切换方式」弹出方式选择抽屉（设计图 1 画面 ①）。0-A 画面 ① 的方式选择页不再作为第一屏。
- 设计图 3 画面 ②、③ 的步骤进度条画错了（第 3 步的圆点写成了「4」且未显示为已完成）。正确表现：从确认页跳回某一步时，其余已完成的步骤都显示对勾，只高亮当前步骤，圆点数字与步骤名一一对应。
- 新流程的添加明细抽屉不显示「常用快捷」；明细为空时也使用同一张明细卡片，只显示「＋ 添加明细」一行；合计放在明细卡片最后一行（设计图 4）。
- 设计图 4 画面 ④ 的搜索框占位文字画成了「选择小分类」，正确为「搜索小分类」（沿用现有文案）。
- 设计图 6 画面 ② 的时间抽屉沿用现有日期时间选择器：「日期」「时刻」两行，同一时间只展开一项（图中为「日期」展开、「时刻」收起）；顶部为标题「时间」+ 关闭 ×，与备注抽屉一致。
- 确认页备注为空时显示灰色占位「添加备注（可选）」，不显示「-」（设计图 6）。

## 设计图与最新规格的差异（实现时以本节和 Issue 正文为准）

以下规格在设计图定稿后才确定，旧图没有重画，实现时按这里的说明处理：

- **步骤是 4 步**：商家 · 账户 · 明细 · 确认。图中的 5 步进度条（含「备注时间」）作废；备注、时间在确认页点击对应行后弹出编辑框修改。
- **已选商家和收支账户合并为一张紧凑卡片**：从第 2 步开始显示在进度条下方，两行（商家一行、账户一行，各带「更换」），每行约 44px。图中商家、账户各占一张大卡片的样式作废。
- **明细全部填好金额后，底部按钮为「去确认」**，直接进入确认步骤。
- **付款分配在明细步骤内展开**，不单独设步骤。
